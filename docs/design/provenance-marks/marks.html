Provenance marks

One X, made four ways. Completed is always a green X and obtained is always an amber slash; only the tool that drew it changes. The player inks it, the save stamps it, we pencil it in, and the old records were typed. Each entry gets its own seed, so no two marks on a page are quite the same.

The recommended set

Real size is the app’s 24 px icon in a 32 px target: the X, the obtained slash, & a quest done in two moments. Enlarged is 3.5×. Most entries are done in one moment, so they get one X. A quest’s slash turns green when it’s done, and the crossing stroke lands later, a little out of register.

Every entry a little different

Eight entries per tool, each seeded by its id: five single X’s, then three quests. The seed picks the filter’s noise, the stamp’s angle & pressure, and the second stroke’s registration. Pressure fades in any direction, by anything from nothing to about half.

On the page

Recommended marks on tracker rows, transcribed from tracker-row.svelte, each seeded by its row. Row text & struck-through state are unchanged; only the tool varies.

One vocabulary. A glance still reads X as done and a slash as obtained, whichever tool drew it. The tool is texture for the player who looks closer.

Quests take two moments. Request for an Apple was obtained & finished from saves, so two stamps. Request for Bait was obtained from a save and finished by hand: an inked stroke across a stamped slash.
