Provenance marks

One X, made four ways. Completed is always a green X and obtained is always an amber slash; only the tool that drew it changes. The player inks it, the save stamps it, we pencil it in, and the old records were typed.

The recommended set

Real size is the app’s 24 px icon in a 32 px target: the X, the obtained slash, & a quest done in two moments. Enlarged is 3.5×. Most entries are done in one moment, so they get one X. A quest is obtained first and finished later, so its green X lands over the amber slash, a little out of register.

Variants

Same X, different handling of the tool. The one marked “pick” is the recommendation. Each real-size row shows the X, the slash, & the quest done in two moments.

On the page

Recommended marks on tracker rows, transcribed from tracker-row.svelte. Row text & struck-through state are unchanged; only the tool varies.

One vocabulary. A glance still reads X as done and a slash as obtained, whichever tool drew it. The tool is texture for the player who looks closer.

Quests show both moments. Request for an Apple was obtained & finished from saves, so two stamps. Request for Bait was obtained from a save and finished by hand: an inked X over a stamped slash.
